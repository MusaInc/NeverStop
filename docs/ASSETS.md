# Assets and licences

Everything in the game is original to Musa Studios except the font.

| Asset | Source | Licence |
|---|---|---|
| City generation, building/ground meshing, shaders, atmosphere, props, trains, ad screens (`src/world/`, `assets/models/`, `assets/ads/`) | Copied from CitySwing (Musa Studios), adapted | Musa Studios own work |
| Vehicles (`assets/vehicles/*.glb`) | `tools/blender/build_vehicles.py`, procedural | Musa Studios own work (original designs, no real makes/logos) |
| Sounds and music (`assets/audio/*.wav`) | `tools/audio/gen_sounds.py`, synthesised with numpy | Musa Studios own work |
| `assets/audio/city_ambience.wav` | CitySwing's synthesised ambience (`gen_audio.py`) | Musa Studios own work |
| Outfit font (`assets/fonts/`) | Google Fonts | SIL Open Font License 1.1 (`assets/fonts/OFL-Outfit.txt`) |
| App icon (`assets/icon_1024.png`) | Rendered from the game's models, `tools/icon_shot.gd` | Musa Studios own work |
| Billboard brands (`assets/ads/`) | Fictional brands drawn for CitySwing | Musa Studios own work |

No third-party code, samples, textures or models. No analytics, ads, tracking
or network access.
